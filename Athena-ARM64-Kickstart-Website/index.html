The code, as it sits in the repo

From .github/workflows/build-arm64-iso.yml, line 1 on. I did not tidy it for the page. What you see is what the file has.

name: Build and Release Athena OS ARM64 ISO

on:
  workflow_dispatch:
    inputs:
      release_tag:
        description: 'Release tag (e.g., v1.0.0-arm64)'
        required: true
        default: 'v1.0.0-arm64'
      fedora_version:
        description: 'Fedora release version'
        required: true
        default: '42'
  push:
    tags:
      - 'v*-arm64'
      - 'v*-aarch64'

env:
  FEDORA_VERSION: ${{ github.event.inputs.fedora_version || '42' }}
  ISO_NAME: athenaos-live-aarch64.iso
